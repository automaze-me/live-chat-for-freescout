Add a live chat bubble to your site. Visitor messages arrive in your FreeScout help desk.

== Description ==

Live Chat for FreeScout shows a chat bubble on every page of your site. Visitors chat directly with your FreeScout installation; messages never pass through WordPress. Requires the Website Chat module on your FreeScout server.
